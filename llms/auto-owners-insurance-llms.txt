# Auto-Owners Insurance

> Mutual property-casualty and life insurer headquartered in Lansing, Michigan, founded in
> 1916. Sells auto, home, condo, renters, life, farm, business, commercial auto, umbrella,
> bonds and specialty (boat, motorcycle, RV, pet, flood) coverage exclusively through a
> network of independent agents across the states it is licensed in. Policyholder
> self-service runs through the Customer Center; agents work through a separate, login-gated
> agent portal.

## Read this first: there is no public API

Auto-Owners Insurance publishes no developer program. As of 2026-09-18 there is no developer
portal, no API reference, no OpenAPI, AsyncAPI, GraphQL SDL, WSDL, Protobuf, MCP server, agent
card, SDK, CLI, published rate limit, API pricing or security.txt on any host it operates.
Every candidate path was probed and recorded:

- https://www.auto-owners.com/developers, /api, /api-docs, /docs, /openapi.json, /swagger.json,
  /graphql, /llms.txt: HTTP 404 (or 400 from the Liferay DXP error page for .json paths)
- https://auto-owners.com/* (apex): 302 to the www home page for every path, including a
  random negative-control path, so a 200 there is never a document
- https://customercenter.auto-owners.com/.well-known/*: HTTP 404 on every path
- https://www.aoins.com/* (independent-agent portal): HTTP 302 to /my.policy, an F5 APM
  access-policy login, for every path
- https://github.com/auto-owners is the company's own GitHub organization (it links back to
  auto-owners.com) and has no public repositories

If you are an agent asked to call an Auto-Owners API: you cannot. Do not guess endpoint paths.
Quotes, policy changes and claims go through an independent agent or the policyholder portal.

## Notes for agents

- The former company blog at https://www.auto-owners.com/ao-blog was removed some time after
  2026-05-25; both /ao-blog and /blog now end at https://www.auto-owners.com/404.
- status.auto-owners.com serves a static "Auto-Owners Insurance Outage" page (noindex), not a
  status page with incident history.
- The site is a Liferay DXP portal; its /o/* platform endpoints (e.g. /o/api) answer 403 and
  belong to the Liferay platform, not to an Auto-Owners product API.
